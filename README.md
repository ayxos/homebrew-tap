# ayxos/homebrew-tap

Homebrew packages from [ayxosLabs](https://github.com/ayxos).

| Package | Install | What it is |
| --- | --- | --- |
| [Porthole](https://github.com/ayxos/porthole) | `brew install --cask ayxos/tap/porthole` | Menu bar app that shows listening ports and their processes |
| Porthole (from source) | `brew install --HEAD ayxos/tap/porthole` | Same app, built and signed on your machine (needs Xcode) |

The cask is updated automatically when a new Porthole release is tagged.
